# REG_MARK_LIB

Библиотека классов на C# для проверки и генерации автомобильных номеров.

## Что делает проект:
1. **Проверяет номера** — метод `CheckMark` проверяет, правильно ли написан российский автомобильный номер (например, `A123BC77`). Он следит за форматом, правильными буквами и корректностью региона.
2. **Выдает следующий номер** — метод `GetNextMarkAfter` берет текущий номер и автоматически генерирует следующий за ним по порядку (например, из `A999AA77` делает `A001AB77`).

## Стек:
* C# / .NET
* Регулярные выражения (Regex)
